# Settlers & Settlements
[-> Modrinth](https://modrinth.com/mod/settlers-and-settlements)

This mod adds vanilla style huts and cottages with custom villagers and pillagers all around your world!

Right now there are two structures:
- The Hunter's cottage (with a custom villager with its own trades!)
- A small pillager hut, with good loot and some pillagers
- If there is demand for this mod, I'll probably add a few more, but this has mainly been a learning project
